# 📱 Neighbourhood Nodes - Android App

Interactive mobile game teaching grid flexibility through real-time decision making.

---

##  How It Works

1. **Select Neighbourhood**: Choose from 6 real UK areas
2. **View Challenge**: Each has unique power problem
3. **Make Decisions**: 6 action buttons affect grid stability
4. **Get Feedback**: ✓ Correct (+20%) or ✗ Wrong (-10%)

---

## 📊 SSEN Data Used

- **Postcodes**: DD2 4TF, DD2 4QN, DD2 4QT, DD2 4QW, DD2 4QX, DD2 4QY
- **Households**: 7, 24, 24, 4, 42, 42 properties
- **Infrastructure**: Primary substations, HV/LV feeders

---

##  Setup

1. Open project in Android Studio
2. Install dependencies (auto-sync)
3. Run on device (API 24+)
